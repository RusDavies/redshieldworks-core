# Security

Report suspected vulnerabilities through GitHub private vulnerability reporting
for this repository once the repository is public and the reporting button or
private intake form is available.

If GitHub private vulnerability reporting is not available, do not post
technical details publicly. Use the maintainer's GitHub profile contact, GitHub
DM/contact mechanism if available, or a minimal GitHub issue that only says you
need a private vulnerability disclosure path. Do not include exploit steps,
secrets, sample payloads, or sensitive data in public issues.

Do not include real customer, taxpayer, banking, payroll, government notice,
credential, portal, or identity data in issues, pull requests, fixtures, or
examples. Use synthetic records.

This repository is pre-1.0. Treat every contract as draft unless a later release
note says otherwise. Security-sensitive contract designs may be held back until
the related authentication, authorization, and risk-review boundaries are ready
for public review.
